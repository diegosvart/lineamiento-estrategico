# Workspace PM — Sistema de Trabajo del PM

Proyecto transversal que formaliza el sistema de trabajo de Diego Morales como PM consultor. Integra el vault Obsidian (conocimiento), Planner/MS365 (ejecución), ms365-sync/ (staging) y el dashboard React (visualización) en un modelo operativo explícito con backlog, roadmap y fuentes de verdad definidas. Ya funciona informalmente; este proyecto lo modela como iniciativa formal dentro del vault.
